# VRLab Project

## 1. 개요 (Overview)

목적 : VR에 대한 연구와 기술 검증을 위해 작업 했습니다.

결과물 : VR 환경에서의 다양한 상호작용을 활용한 컨텐츠 모음을 제작했습니다.



개발 기간: 2025.06.09 - 2025.06.27

개발 환경: 
- Meta Quest 3
- Unity 2022.3.62f
- XR Interaction Toolkit 3.1.2
- XR Hands 1.5.1

## 2. 컨트롤러(Controller)

### Grab & Trigger
- **물체 잡기 / 상호 작용 **: 컨트롤러를 통해 물체를 잡고 잡은 물체와 상호 작용 할 수 있습니다. 아래 
- **Grab Interactor** : 물체를 잡는 컨트롤러에 들어가는 컴포넌트 입니다.
- **Grab Interactable** : 상호 작용 대상인 물체에 들어가는 컴포넌트 입니다. 상호 작용에 대한 Event가 정리되어 있습니다.

### Socket & Lever
- **Socket** : 일치하는 레이어를 가진 오브젝트만을 받아드리는 Socket입니다. 아래 사격 게임에서 총기 & 총기 케이스를 구현했습니다.
- **Lever** : 고정된 물체에서 일정한 각도를 움직이는 컴포넌트 Lever입니다. 사격 게임에서 총기 케이스에 적용 되었습니다.


## 3. 주요 기능 (Key Features)

### 큐비즘
- **물체 잡기/놓기**: 동적으로 생성된 퍼즐과 피스를 자유롭게 잡고 놓을 수 있습니다.
- **물리 기반 상호작용**: 잡은 블럭끼리 물리 효과가 적용되어 현실감 있는 상호작용이 가능합니다.

### 피규어
- **피규어 자세 조작**: 피규어의 관절과 말단의 오브젝트를 조작하여 자세를 변경 할 수 있습니다.
- **피규어 도색** : 원하는 색의 스프레이를 생성해 피규어를 도색할 수 있습니다.
- **Lock Grid Socket** : Socket의 확장 컴포넌트인 Lock Grid Socket을 사용해 진열장을 구현 했습니다.

## 4. 효과 (Effect)
- **Shader** : 자연스로운 오브젝트의 생성과 화면 전환을 위해 Custom Shader를 제작해 Phase와 Dissolve 효과를 구현 했습니다.
