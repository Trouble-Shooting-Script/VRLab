# VRLab Project

## 1. 개요 (Overview)

VR 환경에서의 다양한 상호작용을 활용하여 플레이하는 컨텐츠 모음입니다.

개발 기간: 2025.06.09 - 2025.06.27

개발 환경: 
- Meta Quest 3
- Unity 2022.3.62f
- XR Interaction Toolkit 3.1.2
- XR Hands 1.5.1

## 2. 주요 기능 (Key Features)

### 큐비즘
- **물체 잡기/놓기**: 동적으로 생성된 퍼즐과 피스를 자유롭게 잡고 놓을 수 있습니다.
- **물리 기반 상호작용**: 잡은 블럭끼리 물리 효과가 적용되어 현실감 있는 상호작용이 가능합니다.

### 피규어
- **피규어 자세 조작**: 피규어의 관절과 말단의 오브젝트를 조작하여 자세를 변경 할 수 있습니다.
