## 1. 🚀 프로젝트 개요

### 1.1. ✨ 프로젝트 정보

**VRLab** 프로젝트는 VR 기술 연구와 기술 검증을 목적으로 진행되었습니다. 이 프로젝트를 통해 VR 환경에서의 다양한 상호작용 기법을 탐구하고, 이를 적용한 여러 콘텐츠를 성공적으로 개발했습니다.

-   **개발 기간**: 2025.06.09 - 2025.06.27
-   **개발 환경**:
    -   **HMD**: Meta Quest 3
    -   **Engine**: Unity 2022.3.62f
    -   **주요 패키지**:
        -   XR Interaction Toolkit 3.1.2
        -   XR Hands 1.5.1

### 1.2. 🏗️ 시스템 구조

VRLab 프로젝트는 Unity 엔진과 XR Interaction Toolkit을 기반으로 구축되었으며, 사용자 컨트롤러 입력과 가상 환경 내 객체 간의 상호작용에 중점을 둡니다. 주요 구조는 다음과 같습니다.

-   **Input System**: Meta Quest 3 컨트롤러 및 핸드 트래킹을 통한 사용자 입력 처리
-   **Interaction System**: XR Interaction Toolkit을 활용하여 객체 잡기, 상호작용, 소켓 장착 등의 로직 구현
-   **Custom Components**: `Socket`, `Lever` 등 특정 게임 메커니즘을 위한 커스텀 컴포넌트 개발
-   **Visual Effects**: Custom Shader를 이용한 동적인 화면 전환 및 객체 생성/소멸 효과 구현
-   **Mini-Games**: 다양한 상호작용 요소를 체험할 수 있는 개별 미니 게임 통합

## 2. ⚙️ 시스템 요소

### 2.1. 👋 XR Interaction Toolkit의 Interactor

XR Interaction Toolkit은 VR 환경에서 객체와 상호작용하기 위한 표준화된 방법을 제공합니다. 본 프로젝트에서는 주로 다음 `Interactor` 컴포넌트들을 활용했습니다.

-   **`XR Grab Interactor`**
    -   **역할**: VR 컨트롤러나 손에 부착되어 `XR Grab Interactable` 컴포넌트가 있는 객체를 잡거나 놓는 기능을 담당합니다.
    -   **특징**: 객체의 부모-자식 관계를 변경하거나, 물리적 상호작용을 활성화/비활성화하여 현실적인 그랩(Grab) 경험을 제공합니다.

-   **`XR Direct Interactor`**
    -   **역할**: 물리적인 접촉(손이 객체에 닿는 등)을 통해 `XR Interactable` 객체와 직접 상호작용합니다.
    -   **특징**: 트리거 입력과 결합하여 객체를 활성화하거나 특정 액션을 유발하는 데 사용됩니다.

### 2.2. 🧩 프로젝트 주요 컴포넌트

프로젝트의 특정 요구사항을 충족시키기 위해 다음과 같은 커스텀 상호작용 컴포넌트들을 개발했습니다.

-   **`Socket` 컴포넌트**
    -   **기능**: 특정 조건을 만족하는 객체(예: 특정 레이어)만을 받아들이고 장착할 수 있는 가상 슬롯입니다.
    -   **활용**: 사격 게임에서 총기를 특정 케이스에 정확하게 거치하는 등의 메커니즘에 사용되었습니다.

-   **`Lever` 컴포넌트**
    -   **기능**: 고정된 축을 중심으로 특정 각도 범위 내에서만 회전하도록 설계된 컴포넌트입니다.
    -   **활용**: 사격 게임의 총기 케이스 커버나 스위치와 같이 물리적 레버 동작이 필요한 곳에 적용되어 현실적인 조작감을 제공합니다.

-   **`Lock Grid Socket` (Socket 확장)**
    -   **기능**: `Socket` 컴포넌트의 확장 버전으로, 객체를 격자(Grid) 형태로 정렬하고 고정하는 기능을 추가했습니다.
    -   **활용**: 피규어 룸에서 피규어를 진열장에 깔끔하게 배치하고 잠금으로써 고정된 전시 효과를 구현했습니다.

### 2.3. 🎨 시각 효과 (Phase & Dissolve)

VR 환경의 몰입도를 높이고 사용자 경험을 풍부하게 하기 위해 커스텀 셰이더를 활용한 동적인 시각 효과를 구현했습니다.

-   **`Phase` 효과**
    -   **기능**: 객체의 특정 속성(예: 투명도, 색상)이 시간에 따라 점진적으로 변화하여 객체가 부드럽게 나타나거나 사라지는 효과입니다.
    -   **활용**: 새로운 객체가 생성되거나 특정 인터랙션에 반응하여 객체가 변화할 때 자연스러운 전환을 연출합니다.

-   **`Dissolve` 효과**
    -   **기능**: 노이즈 텍스처를 기반으로 객체의 표면이 점차적으로 사라지거나 나타나는 파괴/생성 효과입니다. 마치 객체가 타거나 녹아내리는 듯한 시각적 충격을 줍니다.
    -   **활용**: 미니 게임의 특정 구간에서 객체의 극적인 소멸이나 새로운 요소의 등장을 강조하는 데 사용되었습니다.

## 3. 🎮 미니 게임

다양한 VR 상호작용 기술을 체험할 수 있도록 다음과 같은 미니 게임 콘텐츠를 개발했습니다.

### 3.1. 🔫 사격 게임

-   **개요**: 권총을 사용하여 타겟을 맞추는 사격 연습 시뮬레이션입니다.
-   **주요 특징**:
    -   **정교한 무기 조작**: `Grab Interactor`를 활용하여 총기를 잡고, 트리거를 당겨 발사하는 현실적인 조작감을 제공합니다.
    -   **총기 거치 시스템**: `Socket` 컴포넌트를 사용하여 총기를 케이스에 정확하게 거치하고 분리할 수 있습니다.
    -   **레버 인터랙션**: `Lever` 컴포넌트를 적용하여 총기 케이스의 커버를 여닫는 등의 물리적 상호작용을 구현했습니다.

### 3.2. 🧊 큐비즘

-   **개요**: 동적으로 생성되는 3D 퍼즐 조각들을 맞추는 물리 기반 퍼즐 게임입니다.
-   **주요 특징**:
    -   **동적 퍼즐**: 게임을 시작할 때마다 새로운 형태의 퍼즐과 조각들이 무작위로 생성됩니다.
    -   **자유로운 배치**: `Grab Interactor`를 통해 퍼즐 조각들을 자유롭게 잡고 3D 공간 내에서 회전시키거나 배치할 수 있습니다.
    -   **물리적 상호작용**: 모든 퍼즐 조각에는 물리 엔진이 적용되어, 조각들이 서로 충돌하거나 중력의 영향을 받는 등 현실감 있는 상호작용을 경험할 수 있습니다.

### 3.3. 🧸 피규어 룸

-   **개요**: 가상 피규어의 자세를 조작하고 도색하며, 진열장에 배치하는 커스터마이징 및 전시 콘텐츠입니다.
-   **주요 특징**:
    -   **피규어 자세 조작**: `Grab Interactor`를 활용하여 피규어의 각 관절과 말단(예: 손, 발)을 직접 움직여 다양한 자세를 만들 수 있습니다.
    -   **커스텀 도색**: 원하는 색상의 스프레이 아이템을 생성하여 피규어의 특정 부분을 자유롭게 도색하고 꾸밀 수 있습니다.
    -   **진열장 시스템**: `Lock Grid Socket` 컴포넌트가 적용된 진열장에 커스터마이징한 피규어를 정렬하여 전시하고 잠글 수 있습니다. 이는 사용자가 만든 창작물을 보관하고 감상하는 공간을 제공합니다.
